# Poke README demo

14 seconds, 1920×1080, 30 fps, silent. A designed terminal illustration based on a
real scripted Poke CLI exchange, not a recording of autonomous model execution.
The source receipts are in assets/exchange.json. The release CLI generated them.

Use a charcoal terminal palette, peach for routing, sage for confirmed receipts,
Inter headlines and JetBrains Mono commands. Two level, readable terminal panes.
No fabricated dashboards, 3D tilt, stock footage, voiceover, scanlines or neon glow.
The request and reply repeat as 62 px hero text at their delivery beats so the
message content remains readable when the two panes shrink on mobile.
The typing is deterministic and every command uses the actual Poke CLI grammar.
Only relevant receipt fields are shown; timestamps and notification diagnostics are
omitted for readability. Message names are registry aliases for numeric endpoints.

## Beats

- 0–3.2: Codex sends “Schema ready. Can you review?”; durable queued receipt.
- 3.2–6.8: request crosses to Pi; Pi reads and acknowledges responsibility.
- 7.1–9.1: Pi sends a parent-routed reply: “Reviewed. Looks good to merge.”
- 8.7–11.5: Codex reads the reply and acknowledges it.
- 11.8–14: hold the two terminals and the result, “A request. A reply. Nothing lost in between.”

Commands remain visible for multiple seconds. The end frame returns to the system,
not an unrelated logo card, and is also the README poster. The GIF uses a reduced
frame rate and width for GitHub; the linked MP4 retains 1080p/30 fps.
